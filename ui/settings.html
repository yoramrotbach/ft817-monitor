Connection
Serial port

Must match the radio's CAT RATE menu setting. Format is fixed at 8N2. RTS and DTR are set low right after the port opens, because some interfaces (Digirig and similar) key the transmitter on them.

Transmit meters

Uses the undocumented command 0xBD. Its neighbor 0xBE is the factory reset, which erases calibration. This app only ever sends read commands, but leave this off if your cable is unreliable. Power output works either way.

Display
Connection changes apply when you click Done.
