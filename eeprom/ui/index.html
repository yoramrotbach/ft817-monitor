817 EEPROM

Backup & restore for the Yaesu FT-817 / FT-817ND / FT-818

1 Back up

Reads the radio's whole EEPROM twice and compares the two reads, so the saved copy is exactly what's in the radio: the 76 calibration values, menu settings, VFOs and memories. This only reads; nothing on the radio changes. Every backup is also kept in the backups folder.

Calibration values (soft-cal menu 1–76)

Tip: also keep a written copy. KA7OEI strongly recommends recording these 76 values before any EEPROM work.

2 Restore

Writes a backup back into the radio. Only bytes that differ are written, and each write is read back and checked. The radio's protected header (addresses 0x00–0x05) and its current CAT baud rate are never changed. A fresh backup of the radio is saved automatically before anything is written.
